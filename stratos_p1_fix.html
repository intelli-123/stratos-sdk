P1-01 - Kill Switch Bypass

Critical

https.get() bypasses enforcement guard.

File: enforcement.js
Lines: 149-163

Problem

Guard patches request() but not get(). Named imports may bypass protection.

Recommended Fix
  • Wrap http.get()
  • Wrap https.get()
  • Call syncBuiltinESMExports()

P1-02 - Provider Coverage Gap

Critical

Hardcoded provider list misses future model providers.

File: enforcement.js
Lines: 57-69

Fix
  • Add api.* wildcard matching
  • Support server-driven block list

P1-03 - Heartbeat Bypass

Critical

401 response silently ignored.

File: index.js
Lines: 237,252

  • Treat 401 as blocked
  • Treat 403 as blocked
  • Enforce minimum 10-second heartbeat

P1-04 - Prompt Privacy Leakage

Critical

Input recording disable flag not applied globally.

File: index.js

  • Pass traceContent flag
  • Respect STRATOS_RECORD_INPUTS=0

P1-05 - Orphan MCP Processes

Critical

Child processes remain running after host exit.

  • Close child stdin on stream end
  • Forward SIGINT
  • Forward SIGTERM

P1-06 - Windows Shell Injection

Critical

shell:true allows command/path injection.

  • Replace spawn with cross-spawn
  • Remove shell:true

P1-07 - Broken Project Recovery

Critical

Package uninstall doesn't restore on failure.

  • Backup package.json
  • Backup lock files
  • Restore if install fails
